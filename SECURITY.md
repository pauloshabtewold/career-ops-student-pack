# Security policy

Report a vulnerability privately with GitHub private vulnerability reporting: open the Security tab of this repository and choose Report a vulnerability. Never describe a vulnerability in a public issue or a pull request.

Say what you found, the steps to reproduce it and the version you ran. You will get an answer in a few days, and a fix is released as a new version.

The latest release is the supported version. Fixes are not backported to older releases, so run `node student/update.mjs` to get the current one.

The pack never asks for a password, a token or a card number, never sends mail, and never submits an application without the student's yes. A report that shows one of those guarantees can be broken is the most useful kind.
